# Commit messages

Write commit messages as conventional commits:

- `feat(scope): summary` for new features
- `fix(scope): summary` for bug fixes
- `chore(scope): summary` for maintenance

Rules:

1. The summary line is imperative, lower-case, and under 72 characters.
2. Reference the package as the scope (`core`, `mcp`, `skills`, ...).
3. See [references/examples.md](references/examples.md) for good and bad examples.
